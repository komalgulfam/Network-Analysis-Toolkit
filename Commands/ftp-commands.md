# FTP Protocol Commands (Port 21)

This file contains standard FTP interactive commands used during service enumeration and interaction.

| Command | Meaning |
| :--- | :--- |
| `USER` | Specify username |
| `PASS` | Send password |
| `PORT` | Active mode data port specification |
| `PASV` | Enter passive mode |
| `LIST` | List files in current directory |
| `CWD` | Change working directory |
| `PWD` | Print working directory |
| `SIZE` | Check file size |
| `RETR` | Retrieve/download a file |
| `QUIT` | End session/disconnect |
