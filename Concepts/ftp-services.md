# FTP Protocol & Service Concepts (Port 21)

## Interactive Commands Overview
- **USER / PASS:** Authentication handshake commands to specify username and transmit password.
- **PORT / PASV:** Active and passive data channel connection modes.
- **LIST / CWD / PWD:** Directory navigation and listing commands.
- **RETR / SIZE:** File retrieval and size verification commands.
- **QUIT:** Clean session termination.
